# Origin

The files in this folder are the Meterless World Model reference implementation, copied unchanged from
[github.com/Meterless/Meterless](https://github.com/Meterless/Meterless), `engines/world-model/reference/src`,
commit `0aa7417` (22 July 2026). License: Apache-2.0 (see `LICENSE`). `../conformance/runner.ts` is the official
conformance suite from `engines/world-model/conformance`, also unchanged.

Run `npm run conformance` in `services/meterless` to check this engine against the suite.
